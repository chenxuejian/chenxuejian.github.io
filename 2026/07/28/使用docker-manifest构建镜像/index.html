使用docker manifest构建镜像

  1. 本地要有两个架构镜像

  2. docker需要开启cli:

    export DOCKER_CLI_EXPERIMENTAL=”enabled”

  3. 需要登录dockerhub(必须操作)

  4. 更改名字,如：

    1. harbor.hyperdl.cn:180/hyperdl/pipeline:v5.0.arm64
    2. harbor.hyperdl.cn:180/hyperdl/pipeline:v5.0.amd64

  5. 开始creat

    1. docker manifest create –insecure chengminghui/pipeline:v5.0 chengminghui/pipeline:v5.0.arm64 chengminghui/pipeline:v5.0.amd64

  6. push命令

    1. docker manifest push docker.io/chengminghui/pipeline:v5.0

  7. inspect查看

    1. docker manifest inspect docker.io/chengminghui/pipeline:v5.0

  8. docker 可以正常pull
    1. docker pull docker.io/chengminghui/pipeline:v5.0
